## 📖 About

**A36 Features** is a stripped-down version of **A36 to Flagship**, a KernelSU module that ports Galaxy S25 (S931B) features to the Galaxy A36.

This version keeps only the cosmetic features: **flagship animations**, **live blur** and **AOD clock transition**. The Galaxy AI apps, models and libraries were removed.

The files come from the S25's `S931BXXUCDZIF` firmware.

> [!CAUTION]
> **INSTALL THIS MODULE AT YOUR OWN RISK.**
>
